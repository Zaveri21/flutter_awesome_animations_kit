# flutter_awesome_animations_kit — Example

Demonstrates all animation types available in the [flutter_awesome_animations_kit](https://pub.dev/packages/flutter_awesome_animations_kit) package.

## Running the example

```bash
cd example
flutter pub get
flutter run
```

## What's included

- All `FlutterAnimatedView` animation types: `fadeIn`, `fadeInUp`, `scale`, `slideRTL`, `slideLTR`, `slideUp`, `slideDown`, `flip`, `bounce`, `scaleLTR`, `scaleCenterZoomOut`, `rotate`, `pulse`, `shake`
- All `FlutterAnimatedText` animation types: `countUp`, `countDown`, `typing`
- Staggered ListView example
